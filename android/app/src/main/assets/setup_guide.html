Getting Started: Quest setup

Horizon Stream's Quest-first setup walks you through console discovery, PlayStation Network sign-in, pairing, and immersive streaming on Meta Quest 3 and Quest 3S. Put the Quest and PlayStation on the same local network and enable Remote Play on the console before starting.

First-time setup

  1. Open Horizon Stream and wait for the unregistered console to appear. Use Refresh search if needed.
  2. Select the discovered console and approve Headset Camera access. It is used only for setup-code scanning.
  3. On a computer with Google Chrome, install the Horizon Stream PSN Authenticator extension.
  4. Open the extension side panel, choose Open PS Remote Play sign-in, and complete the normal PlayStation Network sign-in. Keep the panel open until its one-time QR code appears.
  5. Press any button on a Quest controller to start the headset scan. Hold the computer QR code inside the frame. Horizon Stream retrieves the PSN Account ID locally and saves it for future setup.
  6. On the PS5, open Settings > System > Remote Play > Link Device and leave the eight-digit code visible. Press any Quest controller button when onboarding asks you to scan it.
  7. Keep the PS5 awake and on the same network while pairing. When pairing succeeds, review the controller mappings and press a button to connect.

The sign-in QR code contains a one-time redirect URL. Do not share it. If it is stale or already used, create a new Chrome sign-in and scan the new code once.

Repeat setup

After the PSN Account ID is saved, future onboarding skips the computer sign-in and QR pages and goes directly to the PS5 Link Device instructions. A fresh eight-digit Link Device code is still required for each new console registration.

Controller options

Quest Controller Support is available in Immersive VR Mode. A/B map to Cross/Circle, X/Y to Square/Triangle, triggers to L2/R2, grips to L1/R1, and the left-grip plus left-stick chord to the D-pad. You can also pair a DualSense, DualShock 4, or another Bluetooth gamepad from Quest Settings > Devices > Bluetooth.

Quest Streaming Features

Horizon Stream includes immersive features configured from the app's Settings screen.

Immersive VR Mode

Immersive VR Mode presents the stream as a head-tracked spatial screen. It is required for Quest Touch controller support, pointer controls, and AI 2D-to-3D depth. Press the Quest Meta button to reorient the screen along your full gaze, including vertical pitch; the screen stays level and fixed in the room until you recenter again.

Curved immersive screen

The curved immersive screen wraps the spatial display slightly around you when the headset runtime supports OpenXR cylinder layers. Screen size and curvature can also be changed from the in-stream controls.

Quest Touch Controller Support

Quest Controller Support maps Quest Touch controllers to a virtual PlayStation controller during immersive streams. A/B map to Cross/Circle, X/Y to Square/Triangle, the triggers map to L2/R2, and the sticks map to the PlayStation sticks. Hold the left grip while using the left stick for the D-pad.

  • Tap Quest Menu: PlayStation Options.
  • Double-tap Quest Menu: PlayStation button, unless using a Menu chord.
  • Long-press Quest Menu: send PlayStation Options, then open the in-stream controls.
  • Menu + X: Share; Menu + Y: PlayStation button; Menu + left-stick click: touchpad click.

In the in-stream controls, aim a Quest controller at a row and squeeze its trigger to choose it. You can resize the spatial screen, toggle the curved view, change AI depth, close the panel, or exit streaming. Pointer controls remain available when Quest Controller Support is turned off. A paired Bluetooth controller can also use its D-pad or left stick to move through the panel and its primary button to select a row; its Options/Menu button follows the same single-, double-, and long-press behavior as Quest Menu.

AI 2D-to-3D Depth

AI 2D-to-3D Depth uses Depth Anything V2 asynchronously to infer depth from the 2D game stream and render separate eye views. It requires Immersive VR Mode. Choose Comfort, Balanced, Enhanced, or Strong depth strength. Start with Comfort or Balanced; stronger settings can make the depth more obvious but may introduce artifacts or use more battery.

Note: AI depth may use additional battery and can introduce visual artifacts. If a game has input or visual problems, disable AI depth and use a Bluetooth controller with the flat stream.
