Getting Started: Pairing with PlayStation 5

To use Horizon Stream, you need to link it to your PlayStation 5 console using a Base64 encoded PSN Account ID and a Pairing PIN.

1. Obtain Your PSN Account ID (Base64)

Sony requires a specific 8-byte Account ID to register for Remote Play.

Use the Chrome QR transfer before obtaining a console Link Device code:

  1. In the Horizon Stream Chrome extension, select Open PS Remote Play sign-in and complete Sony's normal sign-in in Chrome.
  2. Reopen the extension when it displays the sign-in QR code.
  3. In Horizon Stream registration, select Scan sign-in QR code and look at that code through the headset. Horizon Stream completes the Account-ID lookup locally.

The QR code contains a one-time PS Remote Play redirect URL, so scan it immediately and never share it. Alternatively, paste that complete redirect URL directly into Horizon Stream, or paste a Base64 Account ID obtained through another method.

2. Obtain a fresh Link Device code from your PlayStation 5

  1. Turn on your PS5 and go to Settings > System > Remote Play.
  2. Toggle on Enable Remote Play.
  3. Select Link Device. The screen will display an 8-digit PIN.

3. Choose a Controller

Quest Controller Gamepad Emulation is available experimentally in Immersive VR Mode. Pair a Bluetooth controller when you prefer conventional or more reliable gamepad input.

  1. Put your controller (e.g., PlayStation DualSense or DualShock 4) into Bluetooth pairing mode. (For PlayStation controllers, hold the PS button and the Share/Create button until the light bar flashes rapidly).
  2. On your Meta Quest, open the Settings menu.
  3. Navigate to Devices > Bluetooth.
  4. Select your controller from the list of available devices to pair it.

4. Connect Horizon Stream

  1. Open the Horizon Stream app on your Meta Quest.
  2. Ensure your headset is on the same local network as your PS5.
  3. Select your console when it appears, or enter its IP address manually.
  4. First provide your Base64 PSN Account ID using the QR transfer, a redirect URL, or an Account ID obtained elsewhere. Then obtain and enter the fresh 8-digit Link Device code from your console screen. This is not your PSN password or sign-in PIN.
  5. Click Register to complete the pairing. You're now ready to stream!

Quest Streaming Features

Horizon Stream includes experimental immersive features configured from the app's Settings screen.

Immersive VR Mode

Immersive VR Mode (Experimental) presents the stream as a head-tracked spatial screen. It is required for Quest Touch controller emulation and AI 2D-to-3D depth.

Quest Touch Controller Emulation

Quest Controller Gamepad Emulation maps Quest Touch controllers to a virtual PlayStation controller during immersive streams. A/B map to Cross/Circle, X/Y to Square/Triangle, the triggers map to L2/R2, and the sticks map to the PlayStation sticks. Hold the left grip while using the left stick for the D-pad.

  • Tap Quest Menu: PlayStation Options.
  • Double-tap Quest Menu: PlayStation button, unless using a Menu chord.
  • Long-press Quest Menu: exit the stream and return to the connections page.
  • Menu + X: Share; Menu + Y: PlayStation button; Menu + left-stick click: touchpad click.

Under Settings → Controls & Input → Exit Stream Button, you can learn another Quest or Bluetooth-gamepad button to exit the stream. The Quest Menu long-press is reserved and cannot be changed; choose Clear assignment to remove a learned button.

AI 2D-to-3D Depth

AI 2D-to-3D Depth (Experimental) uses Depth Anything V2 asynchronously to infer depth from the 2D game stream and render separate eye views. It requires Immersive VR Mode. Choose Comfort, Balanced, Enhanced, or Strong depth strength. Start with Comfort or Balanced; stronger settings can make the depth more obvious but may introduce artifacts or use more battery.

Note: Immersive mode, Touch controller emulation, and AI depth are experimental. If a game has input, visual, or battery-life problems, disable these options and use a Bluetooth controller with the flat stream.
