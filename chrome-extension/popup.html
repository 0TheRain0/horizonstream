Horizon Stream transfer

Use these three steps to move a PSN Account ID from Chrome to Horizon Stream on Quest.

1

Sign in to PSN

Open Sony’s PS Remote Play sign-in in Chrome and complete Sony’s normal sign-in. The extension will capture the final redirect automatically.

2

Paste the redirect URL

Return here after sign-in to create the QR code automatically. If capture did not work, copy the complete final redirect URL from the address bar and paste it here. Do this immediately; the code can be used only once. Never share the URL.

3

Create the QR code

Create the transfer code, then scan it from Horizon Stream’s registration screen on your Quest. Horizon Stream completes the sign-in there.

In Horizon Stream, choose Scan QR code, then look at this code through the headset. Scan it immediately.

The code contains the one-time PSN redirect URL. It is never uploaded or stored by this extension, but anyone who scans it can attempt to finish this sign-in.

This extension opens Sony’s normal sign-in in Chrome. It does not read cookies, page content, passwords, or unrelated browsing. It watches only the final redirect in the sign-in tab it opened, then puts that one-time URL into the QR code. Horizon Stream on your Quest completes the request.
